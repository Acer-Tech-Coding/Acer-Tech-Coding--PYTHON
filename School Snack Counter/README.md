# School Snack Counter

This beginner Python project practices:

- Creating snack boxes with sets
- Adding snacks with `add()`
- Finding shared snacks with set intersection
- Adding values to a list with `append()` and `extend()`
- Counting repeated values with `count()`
- Reversing a list with `reverse()`

Run the counter:

```text
python snack_counter.py
```

Run the tests:

```text
python -m unittest test_snack_counter.py
```
